# 동네 단골 카페 제안 — 포트폴리오용 비공식 랜딩

> **비공식 포트폴리오입니다. 이디야커피(㈜이디야)와 관련이 없습니다.** 로고·공식 이미지·실매장 리뷰를 쓰지 않았고, 가입·주문은 시뮬레이션이며 개인정보를 받지 않습니다. 검색 색인을 막기 위해 `noindex`를 달았습니다.

- 랜딩: `index.html` (7섹션, 모바일 우선, 동의 모드, GA4 권장 이벤트 중심의 dataLayer 이벤트)
- 부록: `appendix/` (전략 요약, 실험 설계, 측정·UTM 규칙, 구조화 데이터 제안 예시, 출처)
- 측정 디버그: `?debug=1`
- 테스트: `npm test` (계산 단위 테스트 8개 + Playwright E2E 9개 × 모바일·데스크톱)

## AI 활용
기획 조사, 코드 작성, 테스트 작성에 AI 코딩 도구(Claude)를 썼습니다. 수치는 출처를 직접 열어 확인했고, 외부 검토 지적은 원문과 대조해 수용하거나 반박했습니다.
